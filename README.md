# Manufacturing Drawing Ballooning & Inspection System

## Overview
This project provides a complete working web application for manufacturing inspection workflows, including login, project management, drawing upload, manual ballooning, a characteristics table, approval status, and export actions.

## Stack
- Frontend: React + Vite + Tailwind + Lucide React
- Backend: Express + MongoDB + Mongoose

## Start backend
```bash
cd backend
npm install
npm run dev
```

## Start frontend
```bash
cd frontend
npm install
npm run dev
```
